# Testimonials Grid Section

A responsive testimonials grid challenge from [Frontend Mentor](https://www.frontendmentor.io) built using HTML and CSS.

## 🚀 What I Learned

This project honestly challenged me more than I expected 😅

At first, I thought I understood CSS Grid pretty well, but while building this layout I realized I still needed to go back and strengthen my basics — especially around:

- `grid-template-columns`
- `grid-column` and `grid-row`
- responsive layouts
- spacing and alignment
- mobile responsiveness

Instead of giving up, I used this project to relearn and practice Grid properly. By the end, I became much more comfortable positioning cards and creating responsive layouts.

## 🎨 Features

- Responsive design
- CSS Grid layout
- Mobile view
- Soft card shadows
- Clean typography
- Profile alignment using Flexbox

## 🛠 Built With

- HTML
- CSS
- CSS Grid
- Flexbox

## 📱 Responsive Design

The layout switches from a multi-column desktop grid to a vertical mobile layout with spacing between cards.

## 💡 Biggest Takeaway

Sometimes the basics are the hardest part.

This challenge reminded me that improving as a developer means going back, relearning, and practicing until things finally click.
